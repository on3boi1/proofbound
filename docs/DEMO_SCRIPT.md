# Three to five minute demo

| Time | Screen and narration |
|---|---|
| 0:00–0:25 | Landing and mint. “PROOFBOUND gives a Research Agent an ownership identity on NEAR. Its history comes from the work it completes.” |
| 0:25–1:00 | Atlas workspace. Show initial Fuel, approved tools and activation. Open a personal job quote and submit. |
| 1:00–1:45 | Finished report. Open source snapshots, calculation inputs, verification checks and measured usage. State whether the run used fixtures or NEAR AI. |
| 1:45–2:40 | Switch to Hybrid and show a customer quote. Open the settled receipt and point to the service split, unused compute refund and 20% owner reinvestment. Show concurrency evidence from the integration test or live records. |
| 2:40–3:20 | Show the denied payout redirection probe. Transfer only after the jobs finish. Show retained Fuel and public history, prior-owner denial and buyer activation. |
| 3:20–3:45 | Close on the Passport. Show a finalized transaction link only for an observed testnet operation. Include repository and reproduction steps. |

For a local-only submission, record the real browser interaction and publish a video. The human publishes the X post. Mention NEAR HACKATHON and include @NEARProtocol and #NEARHackathon.
